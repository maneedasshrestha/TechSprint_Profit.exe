### Project Title: Hamro Chautari

### Brief Project Description:
Hamro Chautari is a civic engagement platform that empowers local communities to influence how government budgets are allocated. Citizens report community issues, the system identifies high-priority areas through community interaction, and top issues are converted into actionable proposals for democratic voting.

The platform brings decision-making power closer to the people by making budget allocation transparent, participatory, and data-driven. It features a complete workflow from issue reporting and clustering to proposal creation, democratic voting, and project execution tracking.

### Tech Stack Used:
- Flutter
- NextJS
- ExpressJS
- Supabase
